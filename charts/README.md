# OttoFlow Helm Charts

This directory contains Helm charts for [OttoFlow](https://github.com/nirmata/ottoflow).

## Installing OttoFlow

```bash
helm install ottoflow oci://ghcr.io/nirmata/ottoflow --version <version> -n ottoflow --create-namespace
```

## Prerequisites

- Kubernetes 1.20+

## Documentation

See the [OttoFlow documentation](https://github.com/nirmata/ottoflow#readme) for full installation and configuration options.
