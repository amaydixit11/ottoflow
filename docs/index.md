# ottoflow

- [Getting Started](getting-started.md) — prerequisites, building the CLI and
  images, and running your first workflow locally or in-cluster.
- [Architecture](architecture.md) — the three binaries/images, execution flow,
  custom resources, step types, and source layout.
- [Configuration](configuration.md) — CLI flags, controller/agent-executor/runner
  flags and env vars, LLM credentials, and Helm chart values.
